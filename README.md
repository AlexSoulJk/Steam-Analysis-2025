# 🎮 Steam-Analysis-2025

Проект для сбора и анализа данных из Steam Web API. Включает различные модули для анализа игр, пользователей и тенденций игровой индустрии.

## 📊 Возможности анализа

### 👥 Анализ социального графа пользователя
- **Статистика по друзьям пользователя:**
  - Анализ игровых предпочтений (популярные жанры)
  - Время, проведенное в играх
  - Активность (последний запуск игр)
  - Уровень Steam-аккаунтов
  - Анализ групп и сообществ
  - Географическое распределение друзей

### 🤖 Система рекомендаций
- **Персонализированные рекомендации игр** на основе:
  - Игровой библиотеки пользователя
  - Предпочтений друзей
  - Схожих игровых паттернов
  - Популярности в регионе

### 📈 Персональная аналитика игрока
- **Трекер игровой активности:**
  - Анализ затрат на игры и внутриигровые покупки
  - Отслеживание прогресса в достижениях
  - Сравнение статистики с другими игроками
  - Визуализация игрового времени по проектам

### 🏗️ Анализ игрового рынка
- **Динамика выпуска игр:**
  - Тренды по жанрам и тегам
  - Выявление перенасыщенных и свободных ниш
  - Соотношение количества игр к размеру аудитории
  - Анализ сезонности выпусков

### 🔍 Факторный анализ успешности игр
- **Исследование корреляций с успехом:**
  - Наличие кооператива и мультиплеера
  - Поддержка модификаций
  - Качество локализации (языки интерфейса, озвучки, субтитров)
  - Ценовая стратегия при релизе
  - Объем контента (достижения, карты, продолжительность)
  - Активность разработчиков (обновления, новости)

### 🌍 Геоаналитика игровых предпочтений
- **Карта популярности жанров:**
  - Региональные предпочтения по жанрам
  - Популярность конкретных игр в разных странах
  - Анализ культурных особенностей геймеров

### 📝 Анализ пользовательских отзывов
- **Сравнительный анализ по регионам:**
  - Сбор и классификация отзывов
  - Влияние локализации на оценки
  - Культурные различия в восприятии игр
  - Анализ sentiment отзывов

### 📊 Анализ издательской активности
- **Статистика игровой индустрии:**
  - Динамика выпуска новых игр
  - Корреляция цены и популярности
  - Рейтинг успешности разработчиков
  - Анализ патчей и обновлений популярных игр
