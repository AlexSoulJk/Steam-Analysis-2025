## 🎯 1. КЛАСТЕРИЗАЦИЯ ИГР И РАСЧЕТ МЕТРИК НАСЫЩЕННОСТИ НИШ

Тип анализа: Кластерный анализ + расчет количественных метрик  
Задача: 
- Провести кластеризацию 10,000 Steam-игр по жанрам, тегам и особенностям геймплея
- Рассчитать коэффициент насыщенности для каждого кластера: (количество новых игр 2023г) / (средний онлайн)
- Построить динамику выпуска игр по кластерам за 2020-2024 гг
- Выявить топ-5 перенасыщенных (коэффициент > 2.0) и топ-5 свободных ниш (коэффициент < 0.5)

## 📊 2. РЕГРЕССИОННЫЙ АНАЛИЗ ФАКТОРОВ УСПЕШНОСТИ ИГР

Тип анализа: Множественная регрессия + машинное обучение  
Задача: Построить прогнозную модель пикового онлайна игры в первый месяц на основе 20+ факторов:
- Количество языков локализации, достижений, карт
- Наличие кооператива, поддержки модов
- Цена при релизе, активность разработчиков
- Целевые переменные: пиковый онлайн и % положительных отзывов

## 🌍 3. КОРРЕЛЯЦИОННЫЙ АНАЛИЗ ЭФФЕКТИВНОСТИ ЛОКАЛИЗАЦИИ ПО РЕГИОНАМ

Тип анализа: Пространственный анализ + корреляционное исследование  
Задача: 
- Проанализировать корреляцию между наличием локализации и оценками игр в 10 регионах Steam
- Рассчитать ROI локализации: (прирост продаж) / (стоимость перевода)
- Сравнить эффективность разных типов локализации (субтитры vs озвучка)
- Построить карту популярности жанров по странам

## ⏱️ 4. КЛАСТЕРИЗАЦИЯ ПОЛЬЗОВАТЕЛЕЙ И ПРОГНОЗИРОВАНИЕ ОТТОКА

Тип анализа: Кластерный анализ + прогнозное моделирование  
Задача: 
- Провести кластеризацию 100,000 игроков по паттернам поведения (время игры, сессии, достижения)
- Разработать модель прогноза оттока с точностью >80% на основе снижения активности
- Проанализировать влияние друзей на игровые предпочтения внутри кластеров
- Создать систему сравнения с "похожими игроками"

## 📈 5. АНАЛИЗ ВРЕМЕННЫХ РЯДОВ ЖИЗНЕННОГО ЦИКЛА ИГР

Тип анализа: Анализ временных рядов + survival analysis  
Задача: 
- Построить кривые выживаемости для 5000 игр после релиза (динамика онлайна)
- Проанализировать эффективность 3 типов обновлений: контентные, багфиксы, ивенты
- Рассчитать корреляцию между частотой обновлений и долгосрочной популярностью
- Разработать оптимальные стратегии ценообразования и выхода DLC
