## 📋 Задачи MVP

### [Задача 1: Кластеризация игр и анализ насыщенности ниш](/doc/tasks/game_clustering.md)
- Кластерный анализ 5000+ игр Steam по жанрам и тегам
- Расчет метрик насыщенности игровых ниш
- Построение динамики выпуска игр по кластерам за 2020-2024 годы

### [Задача 2: Анализ факторов успеха игр](tasks/success_factors.md)
- Выявление факторов, коррелирующих с успехом игр (онлайн, отзывы)
- Анализ корреляции цены и популярности
- Региональный анализ популярности по странам игроков

### [Задача 3: Анализ социального графа](tasks/social_graph.md)
- Построение графов дружбы до 3 уровней глубины
- Анализ игровых предпочтений внутри кругов друзей
- Выявление паттернов влияния в социальных сетях

## 🏗️ Архитектура

- **Сбор данных**: Steam API с ограничением частоты запросов
- **Хранение**: Базы данных SQLite
- **Обработка**: Python с pandas, networkx, scikit-learn
- **Визуализация**: Matplotlib, Plotly
